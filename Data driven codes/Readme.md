This is a Readme file for the Data-driven based Index tracking codes.
There are a total of 9 code files within this modeling technique for index tracking. 
All codes except Clustering are written in python. 

The Clustering.Rmd is an R Markdown file with separate chunks for loading libraries, data, defining the clustering functions 
and the Main-rolling window part to generate the tracking portfolios. 

The Autoencoders.py file has all the 6 autoencoder functions defined as well as the main file call for each passed inside 
a rolling window loop. The output is a single Excel file with weights of each autoencoders saved as a separate sheet within the Excel file.
